# PNG 그림 넣는 곳

여기에 PNG를 넣고 `src/ui/art/images.ts`에 한 줄 등록하면, 그 캐릭터만 PNG로 바뀝니다.
등록하지 않은 캐릭터는 지금처럼 코드(SVG) 그림으로 나옵니다 → 하나씩 바꿔 가도 됩니다.

## 공통 규칙
- **배경은 투명** (PNG 알파 채널). 캐릭터 둘레를 잘라내지 말고 아래 비율의 캔버스를 그대로 쓰세요.
- **오른쪽을 보는 모습**으로 그립니다 (몬스터는 왼쪽). 게임이 상황에 따라 좌우를 뒤집습니다.
- **발이 캔버스 맨 아래**에 닿게 그립니다. 그림자는 게임이 따로 그립니다.
- 비율이 다르면 빈 공간이 생깁니다(가운데 정렬로 줄여서 넣음). 크기는 아래 "권장 크기"(칸 × 30px) 이상이면 선명합니다.
- 픽셀 아트라면 작은 원본을 **정수 배(예: ×10, ×30)로 확대해서**(nearest neighbor) 저장하세요. 폰이 확대하면서 흐려지는 것을 막습니다.

### 무기를 휘두르는 캐릭터 (선택)
제우스·포세이돈은 공격할 때 무기를 휘두릅니다. PNG로도 휘두르게 하려면 **두 장**으로 나눠 그리세요.
- `zeus.png`: 번개를 든 팔을 **뺀** 몸
- `zeus_weapon.png`: 같은 크기 캔버스에 **번개와 그 팔만** (나머지는 투명)
- 무기 층은 아래 축을 중심으로 돕니다 (권장 크기 기준 px, 왼쪽 위가 0,0). 팔이 이 점에서 몸과 이어지게 그리세요.
  - 제우스: 어깨 (546, 486) — 810 × 780 캔버스
  - 포세이돈: 팔꿈치 (564, 558) — 780 × 780 캔버스
- 한 장만 넣으면 휘두르기 없이 그 그림 하나로 나옵니다.

## 배경
| 파일 이름 | 배경 | 권장 크기 (px) |
|---|---|---|
| `bg_earth.png` | 신이 되기 전 (숲·초원) | 2808 × 2400 |
| `bg_zeus.png` | 제우스 (올림포스) | 2808 × 2400 |
| `bg_poseidon.png` | 포세이돈 (바닷속) | 2808 × 2400 |

- 맵 전체 한 장입니다. 화면 폭의 2.4배 넓이라 카메라가 따라가며 일부만 보입니다.
- **위쪽 약 15%**는 먼 배경(나무·신전 기둥·궁전), **나머지**는 캐릭터가 다니는 바닥입니다.
- 폰마다 비율이 조금 달라서 가장자리가 약간 잘릴 수 있습니다. 중요한 그림은 가장자리에 두지 마세요.

## 등록 예 (`src/ui/art/images.ts`)
```ts
export const IMAGE_ART: Record<string, ImageArt> = {
  slime: { body: require('../../../assets/sprites/slime.png') },
  zeus: {
    body: require('../../../assets/sprites/zeus.png'),
    weapon: require('../../../assets/sprites/zeus_weapon.png'),
  },
};

export const BACKGROUND_IMAGES = {
  earth: require('../../../assets/sprites/bg_earth.png'),
};
```
