# ⚡ 신 키우기

아기 신에서 시작해 제우스나 포세이돈이 되는 **방치형(Idle) RPG**입니다.
React Native + Expo(TypeScript)로 만들었고, 픽셀 아트는 이미지 없이 코드(문자열 배열)로 그립니다.

## 게임 규칙

- 신이 **자동으로 공격**합니다. 화면을 터치하면 추가 공격을 합니다.
- 몬스터를 잡으면 **골드**와 **경험치**를 얻습니다. 10번째 몬스터는 **보스**(제한 시간 30초)입니다.
  - 보스에게 지면 한 단계 뒤로 돌아가 골드를 모읍니다. 준비가 되면 "보스 재도전"을 누르세요.
- **성장 단계**
  | 레벨 | 단계 | 공격력 배율 | 스킬 |
  |---|---|---|---|
  | 1 ~ 99 | 👶 아기 신 | ×1 | 없음 |
  | 100 ~ 199 | 🧒 청소년 신 (검) | ×1.5 | 🗡️ 삼연참 |
  | 200 ~ | ⚡ 제우스 / 🔱 포세이돈 (선택) | ×2.5 + 패시브 | 스킬 2개 |
  | 1000 ~ | 〃 | 〃 | + 궁극기 |
- **스킬** (연타 스킬은 실제로 시간 간격을 두고 한 대씩 들어간다)
  - 🗡️ 삼연참 (청소년): 검으로 3번 찌르기, 매번 6배 (6초)
  - **제우스** (패시브: 공격 속도 +30%)
    - ⚡ 낙뢰: 25배 (8초) · 🌩️ 천둥 폭풍: 10초간 공격 속도 3배 (40초)
    - 🌩️ **올림포스의 심판** (Lv.1000): 번개 8줄기, 각 15배 (60초)
  - **포세이돈** (패시브: 치명타 확률 +15%, 치명타 피해 4배)
    - 🌊 대해일: 20배 + 보스 시간 +5초 (8초) · 🔱 삼지창 난무: 10초간 모든 공격 치명타 (40초)
    - 🐙 **크라켄 강림** (Lv.1000): 촉수 6번, 각 20배 + 보스 시간 +10초 (60초)
- **무기**: 몬스터 처치 시 드롭 (일반 2%, 보스 20%)
  - 등급: 커먼 · 레어 · 에픽 · 레전드 · **초월** (포세이돈의 삼지창, 제우스의 번개)
  - **등급업**: 같은 무기 3개 → 다음 등급 무기 1개 (무작위)
  - **초월 무기**: 등급업 불가. 초월 무기 1개를 재료로 강화(+1당 +20%)하는 것이 유일한 강화 방법
  - 초월 무기는 주인 신이 들면 위력 ×1.5
  - 더 센 무기를 얻으면 자동 장착
- **강화**(골드): 신력(공격력), 시전 속도, 치명타, 공물(골드 획득량). ×1 / ×10 / ×50 / ×100 단위로 한 번에 살 수 있고, 돈이 모자라면 살 수 있는 만큼만 산다.
- **오프라인 보상**: 앱을 꺼 둔 동안(최대 8시간) 골드 50%, 경험치 10%를 얻습니다.

## 프로젝트 구조

```
App.tsx                 # 게임 루프(0.1초마다 tick), 자동 저장, 팝업 관리
src/
  game/                 # 게임 규칙 (UI와 분리 → Node에서 단독 실행 가능)
    types.ts            #   상태 타입
    balance.ts          #   ⭐ 밸런스 공식 (체력, 골드, 경험치, 강화 비용, 신, 스킬)
    engine.ts           #   tick / tap / castSkill / buyUpgrade / 무기 합성·강화 / offlineReward
    weapons.ts          #   무기 목록, 등급, 드롭 확률
    format.ts           #   큰 숫자 표시 (1.23K, 4.5M, 7.8aa ...)
  storage/save.ts       # 기기 저장 (AsyncStorage)
  ui/
    sprites.ts          #   픽셀 아트 데이터 ← 그림 수정은 여기
    effects.tsx         #   전투 이펙트 (참격, 번개, 해일, 촉수, 파편, 데미지 숫자...)
    PixelSprite.tsx     #   픽셀 아트 렌더러
    BattleView.tsx      #   전투 화면
    Panels.tsx          #   상단 정보, 스킬 버튼, 강화 목록
    Modals.tsx          #   오프라인 보상, 진화, 신 선택 팝업
scripts/simulate.ts     # 자동 플레이 시뮬레이터 (밸런스 확인용)
```

## 실행

```bash
npm install
npm start               # QR 코드 → 아이폰 Expo Go 앱으로 실행
npm run web             # 브라우저에서 실행
npm run typecheck
npm run simulate        # 시간대별 레벨/스테이지 (제우스)
npm run simulate poseidon
```

현재 밸런스(시뮬레이터 기준, 무기 운에 따라 편차 있음): Lv.100 약 3~4분, Lv.200 약 10~20분, Lv.1000 약 1.5~4시간.
