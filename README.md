# ⚡ 신 키우기

아기 신에서 시작해 제우스나 포세이돈이 되는 **방치형(Idle) RPG**입니다.
React Native + Expo(TypeScript)로 만들었고, 픽셀 아트는 이미지 없이 코드(문자열 배열)로 그립니다.

## 게임 규칙

- **화면 구성** (폰 화면 전체가 게임)
  - 맵이 화면 전체를 채우고, 위에는 레벨·골드·다이아가 반투명하게 겹친다. Lv 위의 작은 난이도 칸을 누르면 난이도 선택 창
  - **맵은 화면보다 넓다** (가로 2.4화면, 세로 1.6화면). 카메라가 신을 따라가고, 맵 끝에서는 멈춘다
  - 몬스터는 신 주변 화면 가장자리 바깥에서 여러 방향으로 나타난다
  - 배경: 신이 되기 전 숲 속 초원 / 제우스 구름 위 올림포스 신전(대리석 바닥, 기둥, 금빛 번개 문양) / 포세이돈 바닷속 궁전(모래, 산호, 해초, 물방울)
  - 맵 아래쪽에 동그란 스킬 버튼 (쿨타임 동안 남은 초가 보인다, 궁극기는 주황 테두리)
  - 맨 아래 탭 4개: 🗺️ 컨텐츠(일일 던전·레이드·상점) / ⚔️ 무기강화 / 💪 힘강화(골드 강화) / 📈 스킬강화
    - 탭을 누르면 화면 절반 높이의 창이 아래에서 올라온다. 같은 탭이나 ✕를 누르면 닫힌다. 창이 열려 있어도 전투는 계속된다
- **필드 전투**
  - 전투 화면 아무 곳이나 **눌러서 끌면** 가상 조이스틱이 나타나고 그 방향으로 움직입니다.
  - **멈추면** 가장 가까운 몬스터를 자동으로 공격합니다 (움직이는 동안은 공격하지 않음). 짧게 톡 치면 추가 공격.
  - 10스테이지마다 보스 스테이지 (제한 시간 30초)
  - 몬스터가 붙으면 1초마다 공격합니다. 신의 체력이 0이 되면 그 스테이지를 처음부터 (보스면 한 스테이지 뒤로 가서 파밍).
    떨어져 있으면 체력이 초당 6%씩 회복 → 빠져서 회복하고 다시 싸우는 전략
  - 한 스테이지에 몬스터 8~12마리가 한 방향에서 무리 지어 몰려온다 (보스 스테이지: 보스 + 졸개 4마리)
  - 자동 공격은 맞은 몬스터 주변에도 50% 범위 피해: 제우스는 번개가 주변 몬스터로 **이어지고**, 포세이돈은 파도 물결이 **퍼진다**
  - 광역 스킬(대해일·대지진·소용돌이·회오리 검무·연쇄 번개·궁극기)은 모든 몬스터를, 나머지는 가장 가까운 한 마리를 때립니다.
- **난이도** (각 5000스테이지, 5000스테이지를 깨면 다음 난이도 개방)
  | 난이도 | 몬스터 체력·공격력 | 골드 |
  |---|---|---|
  | 쉬움 | 기본 | 기본 |
  | 보통 | 쉬움² | 쉬움² |
  | 어려움 | 쉬움³ | 쉬움³ |
  | 극악 | 쉬움⁴ | 쉬움⁴ |
  - 몬스터·스토리·스테이지는 모든 난이도가 같다. 골드도 같은 지수로 올려야 보통 이상을 깰 수 있다 (무기·레벨·스킬 배율은 제곱되지 않아서 높은 난이도일수록 실제로 어렵다)
  - 쉬움 5000스테이지 체력이 약 10⁷⁵ → 극악은 약 10³⁰⁰ (JavaScript 숫자 한계 10³⁰⁸ 바로 아래)
  - 난이도를 바꾸면 그 난이도의 최고 스테이지에서 이어 한다 (Lv 위 난이도 칸 → 선택 창)
- **스토리**: 500스테이지마다 한 장, 총 10장. 새 장에 들어가면 컷신 (난이도마다 한 번씩)
  1. 오염된 숲(독 슬라임) 2. 어둠의 동굴(흡혈 박쥐) 3. 망자의 들판(해골 전사) 4. 저승의 문(원령) 5. 대장간 섬(키클롭스)
  6. 플레그라 평원(기간테스 전사) 7. 무너진 산맥(투석병) 8. 분노한 바다(바다 거인) 9. 거인의 성채(거인 군주) 10. 타르타로스의 문(티포에우스의 자식)
- **성장 단계**
  | 레벨 | 단계 | 공격력 배율 | 스킬 |
  |---|---|---|---|
  | 1 ~ 999 | 👶 아기 신 | ×1 | 없음 |
  | 1000 ~ 1999 | 🧒 청소년 신 (검) | ×1.5 | 🗡️ 삼연참 |
  | 2000 ~ 2999 | 🛡️ 성인 신 (투구·방패·긴 검) | ×2 | + 🌪️ 회오리 검무 |
  | 3000 ~ | ⚡ 제우스 / 🔱 포세이돈 (선택) | ×2.5 + 패시브 | 2개 → Lv.4000·6000·8000에 1개씩 → 5개 |
  | 10000 ~ | 〃 | 〃 | + 궁극기 (총 6개, 레이드 보상까지 7개) |
  - 레벨 숫자는 예전의 10배지만, 경험치 공식도 10배 촘촘하게 바꿔서 성장 속도는 그대로다
- **스킬** (연타 스킬은 실제로 시간 간격을 두고 한 대씩 들어간다)
  - 🗡️ 삼연참 (청소년~): 3번, 매번 6배 (6초) · 🌪️ 회오리 검무 (성인~): 4번, 매번 8배 (10초)
  - **제우스** (패시브: 공격 속도 +30%)
    - ⚡ 낙뢰: 25배 (8초) · 🌩️ 천둥 폭풍: 10초간 공격 속도 3배 (40초)
    - ⛓️ 연쇄 번개 (Lv.4000): 5번, 매번 10배 (15초) · 🦅 독수리 강하 (Lv.6000): 45배, 무조건 치명타 (20초)
    - 👑 신들의 왕 (Lv.8000): 다른 스킬 쿨타임 전부 초기화 (90초)
    - 🌩️ **올림포스의 심판** (Lv.10000): 번개 8줄기, 각 15배 (60초)
  - **포세이돈** (패시브: 치명타 확률 +15%, 치명타 피해 4배)
    - 🌊 대해일: 20배 + 보스 시간 +5초 (8초) · 🔱 삼지창 난무: 10초간 모든 공격 치명타 (40초)
    - 🌀 소용돌이 (Lv.4000): 6번, 매번 9배 (15초) · 🌋 대지진 (Lv.6000): 45배 + 보스 시간 +5초 (20초)
    - 🐚 바다의 축복 (Lv.8000): 다른 스킬 쿨타임 절반 + 레이드 중 신의 체력 30% 회복 (60초)
    - 🐙 **크라켄 강림** (Lv.10000): 촉수 6번, 각 20배 + 보스 시간 +10초 (60초)
  - 스킬로 늘리는 보스 시간은 한 번의 보스전·레이드에서 **최대 30초**까지 (무한히 버티기 방지)
- **탈것**: 제우스는 구름 위에, 포세이돈은 상어를 타고 싸운다
- **몬스터**: 독 슬라임 → 흡혈 박쥐 → 해골 전사 → 원령 → 분노한 키클롭스 (스테이지마다 바뀌고, 10번째는 보스)
- **무기**: 몬스터 처치 시 드롭 (일반 2%, 보스 20%)
  - 등급: 커먼 · 레어 · 에픽 · 레전드 · **초월** (포세이돈의 삼지창, 제우스의 번개)
  - **등급업**: 같은 무기 3개 → 다음 등급 무기 1개 (무작위)
  - **초월 무기**: 등급업 불가. 초월 무기 1개를 재료로 강화(+1당 +20%)하는 것이 유일한 강화 방법
  - 초월 무기는 주인 신이 들면 위력 ×1.5
  - 더 센 무기를 얻으면 자동 장착
- **💎 다이아 / 🪙 강화코인**
  - 💎 얻는 법: 스테이지 보스 첫 처치 +10, 레이드 클리어 +30 (인앱 결제는 아직 없음)
  - **무기 뽑기**: 💎100 = 1회, 💎1000 = 11회 (마지막 1개는 레전드 이상 확정: 레전드 90% / 초월 10%)
    - 확률: 커먼 50% · 레어 30% · 에픽 15% · 레전드 4.5% · 초월 0.5%
  - 🪙 얻는 법: 레이드 (클리어 3 + 단계, 실패 시 넣은 피해만큼 최대 2), 상점 💎100 → 🪙10
  - **스킬 강화** (🪙, 최대 20레벨, 비용 2·4·6…): 공격 스킬은 레벨당 피해 +15%, 버프·유틸 스킬은 레벨당 쿨타임 −2.5%
  - **✨ 패시브 스킬** (🪙, 스킬강화 탭, 누르지 않아도 항상 적용)
    - 👹 거인 사냥꾼: 보스(스테이지·레이드) 피해 레벨당 +10%, 최대 30레벨 (비용 5·10·15…)
    - 🌟 신의 각성: 4단계 순환, 단계마다 5번씩 강화 → 1단계 🔥 피해 +5% → 2단계 👟 이동 속도 +3% → 3단계 ⚡ 공격 속도 +3% → 4단계 🎯 치명타 피해 +8% → 다시 1단계. 레벨 제한 없음 (비용 3, 4, 5… 한 번마다 1씩 오름)
- **강화**(골드): 신력(공격력), 시전 속도, 치명타, 🗡️ 치명타 피해(레벨 제한 없음, 레벨당 +1%p, 비용 레벨당 ×2.0으로 비쌈), 공물(골드 획득량). ×1 / ×10 / ×50 / ×100 단위로 한 번에 살 수 있고, 돈이 모자라면 살 수 있는 만큼만 산다.
- **📅 일일 던전: 기간토마키아** (Lv.3000 신, **하루 1번**, 90초)
  - 거인이 끝없이 몰려온다: 기간테스 전사 → 투석병 → 보스(제우스: 포르피리온 / 포세이돈: 폴리보테스) → 다시 처음부터, 한 바퀴마다 체력 ×1.6
  - 불사의 거인: 평소 피해 ½ · 헤라클레스가 6초마다 화살 → 3초간 「필멸의 표식」 피해 ×1.5
  - 적이 공격하지 않아 실패가 없다. 시간이 끝나거나 나가면 **넣은 피해의 총합**으로 보상
  - 점수 = 피해 총합 ÷ 입장 시 내 초당 피해 (평타 몇 초어치를 넣었나) → 스킬·표식 타이밍·터치를 잘할수록 높다
  - 보상: 골드 = 최고 웨이브 몬스터 골드 × 점수 × 0.5 / 💎 = 점수 ÷ 5 (하루 최대 💎100)
  - 첫 참전 보상 스킬: 제우스 🏹 「거인 사냥」(번개+화살 8연타, 각 9배) / 포세이돈 🏝️ 「니시로스 투척」(섬을 던져 70배)
- **레이드: 티포에우스** (하루 입장권 3장. 입장권은 **실패할 때만** 쓰고 클리어하면 돌려받는다)
  - 🐍 **티포에우스** (Lv.5000, 120초)
    - 체력 60%: 「힘줄 절단」 8초간 공격력 ×0.2 → 헤르메스와 판이 힘줄을 되찾아 오면 10초간 ×1.5
    - 불길 브레스: 12초마다 1.2초 기절 (체력 25% 이하 분노 → 6초마다)
    - 첫 클리어: 자기 신의 초월 무기 확정
  - **단계**: 클리어할 때마다 1단계씩 올라가고, 적이 기하급수로 강해진다 (n = 단계)
    | 능력치 | 공식 | 한 단계마다 |
    |---|---|---|
    | 체력 | 기준 웨이브 + 8n 웨이브의 몬스터 체력 × 50 | ×3.8 |
    | 공격력 | 4 × 1.45ⁿ, 3초마다 신을 공격 (브레스는 3배) | ×1.45 |
    | 방어력 | 20 × (1.5ⁿ − 1), 받는 피해 × 100 / (100 + 방어력) | ×1.5 |
  - 레이드 안에서는 **신의 체력**(100 × 1.5^((레벨−3000)/1000))이 있고, 0이 되면 쓰러져서 실패
  - 적 능력치는 내 전투력과 무관한 고정값이라, 막히면 성장해서 다시 도전하면 된다. 보상(골드·경험치)도 단계마다 1.4배
  - 처음 도전할 때는 입장·보스 등장·힘줄 절단 등 순간마다 컷신 대사가 나오고, 대사가 떠 있는 동안 시간이 멈춘다
  - 실패하거나 포기해도 넣은 피해 비율만큼(절반) 골드·경험치를 받는다
- **오프라인 보상**: 앱을 꺼 둔 동안(최대 8시간) 골드 50%, 경험치 10%를 얻습니다.

## 프로젝트 구조

```
App.tsx                 # 게임 루프(0.1초마다 tick), 자동 저장, 팝업 관리
src/
  game/                 # 게임 규칙 (UI와 분리 → Node에서 단독 실행 가능)
    types.ts            #   상태 타입
    balance.ts          #   ⭐ 밸런스 공식 (체력, 골드, 경험치, 강화 비용, 신, 스킬)
    engine.ts           #   tick / tap / castSkill / buyUpgrade / 무기 합성·강화 / offlineReward
    weapons.ts          #   무기 목록, 등급, 드롭 확률
    economy.ts          #   다이아·강화코인·뽑기 확률·스킬 강화 수치
    raids.ts            #   레이드 데이터 (페이즈, 기믹 수치, 보상)
    story.ts            #   메인 스토리 10장 + 레이드 컷신 대사
    field.ts            #   필드 전투 (좌표, 몬스터 무리, 접촉 피해, 신의 체력)
    format.ts           #   큰 숫자 표시 (1.23K, 4.5M, 7.8aa ...)
  storage/save.ts       # 기기 저장 (AsyncStorage)
  ui/
    art/                #   ⭐ 카툰 일러스트(벡터 SVG): heroes·monsters·raid.tsx ← 그림 수정은 여기
    sprites.ts          #   예전 픽셀 아트 (art/에 없는 이름만 이걸로 그린다)
    effects.tsx         #   전투 이펙트 (참격, 번개, 해일, 촉수, 파편, 데미지 숫자...)
    PixelSprite.tsx     #   그림 렌더러 (벡터 그림이 있으면 벡터, 없으면 픽셀)
    BattleView.tsx      #   전투 화면
    Panels.tsx          #   상단 정보, 스킬 버튼, 강화 목록
    Modals.tsx          #   오프라인 보상, 진화, 신 선택 팝업
    Hud.tsx             #   전체 화면 UI: 스킬 버튼, 하단 탭, 절반 높이 창
    Background.tsx      #   맵 배경 (초원 / 올림포스 / 바닷속 궁전, SVG)
    ShopUI.tsx          #   상점(뽑기·강화코인), 스킬 강화, 뽑기 결과
    RaidUI.tsx          #   레이드 목록, 컷신 대화창, 레이드 결과
scripts/simulate.ts     # 자동 플레이 시뮬레이터 (밸런스 확인용)
scripts/raid-sim.ts     # 레이드 클리어 시뮬레이터
```
